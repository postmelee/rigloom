# 사용자 가이드

[English](en.md) · [README](../../README.ko.md)

상태: GLB 검사와 #4 매핑·바인드 검증 구현이며 릴리스·공개 배포하지 않았습니다. README대로 로컬 빌드하세요. 현재 UI는 영어이며 이 한국어·영어 문서 쌍은 같은 동작을 설명합니다.

1. **Open GLB**로 자체 포함 glTF 2.0 GLB를 선택합니다.
2. 개수·노드 관계·진단을 확인합니다. 구조 또는 스킨 데이터 오류는 미리보기를 차단합니다. 매핑 오류는 향후 변환 전에 해결해야 하지만 표시 가능한 모델의 미리보기를 숨기지는 않습니다. 경고는 남은 제한을 설명합니다.
3. Front·Side·Free 시점, 드래그 회전, 스크롤 확대, 오른쪽 드래그 이동을 사용합니다. 기존 본이 있으면 겹쳐 표시합니다. 시점 버튼은 카메라만 바꾸며 모델 방향·바인드 자세를 변경하지 않습니다.
4. 검사를 취소하거나 다른 파일로 교체할 수 있습니다. 이전 결과는 최신 선택을 덮어쓰지 않습니다.
5. **Humanoid mapping**에서 제안된 원본 노드를 검토합니다. 필수 본은 별표로 표시하며 나머지는 **Optional bones**를 펼쳐 확인합니다. 노드 또는 **Unassigned**를 선택한 뒤 **Validate mapping**을 누릅니다. 이름이 중복되어 후보가 여러 개이면 직접 선택해야 합니다. 제안은 이름과 일반 별칭을 사용하며 해부학적 위치를 자동 판별하지 않습니다.
6. **Save mapping**은 지원하는 55개 본(필수 15개)의 선택을 저장합니다. 미지정 또는 오류가 있는 선택도 검증 후 저장하여 작업을 보존할 수 있습니다. **Load mapping**은 바이트가 같은 GLB의 선택을 불러오며 다시 검증해야 적용됩니다. 변경된 GLB, 지원하지 않는 스키마, 잘못된 매핑은 거부합니다. 저장 파일은 SHA256 원본 식별값과 노드 선택을 담으며 모델 형상은 포함하지 않습니다. 원본 GLB를 보관하세요.
7. **Save report**는 검사·매핑·바인드·가중치 결과를 내려받습니다. 매핑을 변경하거나 불러오면 검증이 끝날 때까지 두 저장 버튼이 비활성화됩니다. 두 JSON 파일 모두 편집 가능한 프로젝트나 VRM이 아닙니다. 헤더 버튼으로 테마를 전환합니다. 파일·버튼은 키보드로 접근할 수 있지만 3D 조작의 완전한 키보드 지원은 후속 작업입니다.

## 현재 지원 범위와 오류

| 입력 | 현재 동작 / 해결 방법 |
|---|---|
| 단일 장면, 여러 메시 | 허용하며 캐릭터 수를 자동 판별하지 않습니다 |
| 조밀한 삼각형 데이터, 내장 BIN, 일반적인 기본 PBR | 검사 후 뷰어로 전달하며 표시 단계에서 실패할 수도 있습니다 |
| 기존 스킨 / 스킨 없음 | 기존 관절 참조·가중치·변환·역바인드 검사 / 검증할 스킨 없음이며 자동 복구·리깅하지 않습니다 |
| 누락·중복·잘못된 부모 관계의 휴머노이드 매핑 | Humanoid mapping에서 선택을 수정하세요. 매핑한 본 사이의 보조 노드는 허용합니다 |
| 잘못된 가중치·합계·관절 인덱스·역바인드 형식 | 미리보기를 차단합니다. 원본 도구에서 수정하며 자동 정규화·재작성하지 않습니다 |
| JOINTS/WEIGHTS 세트가 두 개 이상 | 모든 세트를 검사하지만 현재 뷰어가 네 영향값만 사용하므로 미리보기를 보류합니다 |
| 스킨 메시 월드 변환의 역행렬이 없음 | 바인드 검사는 통과할 수 있지만 현재 뷰어가 변환을 안전하게 역산하지 못하므로 미리보기를 보류합니다 |
| 행렬과 TRS 필드 동시 사용 또는 명시적 로컬 노드 행렬의 전단 | 차단하며 원본 도구에서 로컬 변환을 수정하세요 |
| 바인드·휴지 자세 검토 경고 | 원본 자세를 확인하세요. 관절 월드 행렬 × 역바인드가 서로 다른 것은 의도된 자세일 수 있어 곧바로 데이터 손상으로 판단하지 않습니다 |
| 버퍼·이미지의 외부 URI 또는 data URI | 차단하며 버퍼를 BIN에, 이미지를 버퍼 뷰에 내장하세요 |
| 압축·특수 재질을 포함한 모든 확장 | 차단하며 기본 glTF 버전을 준비하고 원본을 보관하세요 |
| 희소 접근자 또는 삼각형 이외 형상 | 차단하며 조밀한 속성과 삼각형으로 내보내세요 |
| 빈 접근자, 잘못된 POSITION·인덱스 형식 | 보고서와 함께 차단하며 비어 있지 않은 FLOAT VEC3 위치와 부호 없는 SCALAR 인덱스를 정규화 없이 출력하세요 |
| 잘린 파일, 잘못된 참조·순환·바이너리 범위 | 차단하며 원본 도구에서 복구·재출력하세요 |
| 입력 애니메이션 | 개수만 확인하고 정적으로 표시하므로 원본을 보관하세요 |
| FBX, PMX/PMD, BLEND | 직접 읽지 않으며 적절한 기존 도구에서 GLB로 내보내세요 |

Blender 등에서 GLB를 준비할 때 축·크기·재질·내장 텍스처·본·가중치·애니메이션을 출력 후 확인하세요. 변환 중 기능이 손실될 수 있습니다. 형식별 애드온은 각자의 라이선스가 있으며 모델 권리도 그대로 적용됩니다. 원본을 보관하세요.

역바인드는 생략할 수 있으며 이때 단위 행렬을 사용합니다. 접근자는 스킨 관절 수 이상의 행렬을 포함할 수 있습니다. 비항등 변환과 바인드 형상 변환을 보존합니다. 수치 검사 통과가 제작자가 의도한 중립 자세나 자연스러운 변형을 증명하지는 않습니다. [검증 경계](../architecture.md#mapping-and-existing-skin-contracts)를 확인하세요.

WASM 초기화가 실패하면 `npm run build` 후 새로고침하세요. WebGL이 없으면 검사·보고서는 사용할 수 있으나 미리보기에는 WebGL이 필요합니다. 로더가 실패해도 검사 보고서는 남습니다. 실측한 최대 파일 크기·정점·텍스처·본 한도나 폭넓은 브라우저 지원을 약속하지 않으며 큰 파일은 메모리를 소진할 수 있습니다. [검증 기록](../validation.md)을 확인하세요.

## 예정된 출력과 모델 권리

VRM 1.0 출력, 관절 드래그, 가중치 생성, 진단 동작, 프로젝트 복원은 계획 단계입니다. 현재 모델 출력 기능은 없습니다. 매핑은 기존 선택적 손가락 본도 지원하지만 본을 생성하거나 형상에서 손가락을 분리하지 않습니다. 향후 유효한 본·바인드·가중치와 명시적인 이름·저자·이용 조건을 요구하고, 검증된 리소스를 보존하며 애니메이션·재질 변경을 보고할 예정입니다. 권리를 모른다고 CC0로 바꾸지 않습니다. PBR을 자동으로 MToon으로 바꾸지 않으며 표정·시선·물리는 별도 후속 작업입니다.

업로드 서비스는 설정하지 않았습니다. 런타임 리소스는 동일 출처이며 모델 URI 리소스는 로드 전에 차단합니다. 테스트는 합성 입력을 대상으로 하며 미래의 모든 배포를 보장하지 않습니다. 개인 모델은 저장소 대신 git 제외 경로 `.local/`에 둡니다. 다운로드·테스트 허용이 영상 사용·재배포 허용을 뜻하지 않습니다.

공개 릴리스·배포·배포물의 모델 편입은 해당 배치의 소유자 승인이 필요합니다. [한영 릴리스 정책](../release-policy.md)을 확인하세요.
