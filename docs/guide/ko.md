# 사용자 가이드

[English](en.md) · [README](../../README.ko.md)

상태: GLB 검사·매핑·바인드 검증과 #5 기존 리그의 VRM 1.0 출력을 구현했고 PR 검토를 기다리며 릴리스·공개 배포하지 않았습니다. README대로 로컬 빌드하세요. 현재 UI는 영어이며 이 한국어·영어 문서 쌍은 같은 동작을 설명합니다.

1. **Open GLB**로 자체 포함 glTF 2.0 GLB를 선택합니다.
2. **Model**에서 개수·노드 관계·진단을 확인합니다. 구조 또는 스킨 데이터 오류는 미리보기를 차단합니다. 매핑 오류는 출력 전에 해결해야 하지만 표시 가능한 모델의 미리보기를 숨기지는 않습니다. 경고는 남은 제한을 설명합니다.
3. Front·Side·Free 시점, 드래그 회전, 스크롤 확대, 오른쪽 드래그 이동을 사용합니다. 기존 본이 있으면 겹쳐 표시합니다. 시점 버튼은 카메라만 바꾸며 모델 방향·바인드 자세를 변경하지 않습니다.
4. 검사·출력을 취소하거나 다른 파일로 교체할 수 있습니다. 이전 결과는 최신 선택을 덮어쓰지 않습니다.
5. 상단의 **Mapping**에서 제안된 원본 노드를 검토합니다. 필수 본은 별표로 표시하며 나머지는 **Optional bones**를 펼쳐 확인합니다. 노드 또는 **Unassigned**를 선택한 뒤 **Validate mapping**을 누릅니다. 이름이 중복되어 후보가 여러 개이면 직접 선택해야 합니다. 제안은 이름과 일반 별칭을 사용하며 해부학적 위치를 자동 판별하지 않습니다.
6. **Save mapping**은 지원하는 55개 본(필수 15개)의 선택을 저장합니다. 미지정 또는 오류가 있는 선택도 검증 후 저장하여 작업을 보존할 수 있습니다. **Load mapping**은 바이트가 같은 GLB의 선택을 불러오며 다시 검증해야 적용됩니다. 변경된 GLB, 지원하지 않는 스키마, 잘못된 매핑은 거부합니다. 저장 파일은 SHA256 원본 식별값과 노드 선택을 담으며 모델 형상은 포함하지 않습니다. 원본 GLB를 보관하세요.
7. **Model → Save report**는 검사·매핑·바인드·가중치 결과를 내려받습니다. 매핑을 변경하거나 불러오면 검증이 끝날 때까지 두 저장 버튼이 비활성화됩니다. 두 JSON 파일 모두 편집 가능한 프로젝트나 VRM이 아닙니다. **Dark / Light**로 UI와 3D 화면의 테마를 함께 전환합니다. 처음에는 시스템 테마를 따르고 직접 선택하면 그 값을 기억합니다. **Model / Mapping / Export** 중 하나의 패널만 열리며 선택한 버튼을 다시 누르거나 **×**, **Esc**로 닫습니다. 좁은 화면에서는 미리보기 아래에 조작부를 표시합니다. 파일·버튼은 키보드로 접근할 수 있지만 3D 조작의 완전한 키보드 지원은 후속 작업입니다.

## 현재 지원 범위와 오류

| 입력 | 현재 동작 / 해결 방법 |
|---|---|
| 단일 장면, 여러 메시 | 허용하며 캐릭터 수를 자동 판별하지 않습니다 |
| 조밀한 삼각형 데이터, 내장 BIN, 일반적인 기본 PBR | 검사 후 뷰어로 전달하며 표시 단계에서 실패할 수도 있습니다 |
| 기존 스킨 / 스킨 없음 | 기존 스킨 데이터를 검사하고 출력 여부를 판단 / 스킨이 없으면 검사만 가능하며 자동 복구·리깅하지 않습니다 |
| 누락·중복·잘못된 부모 관계의 휴머노이드 매핑 | Mapping에서 선택을 수정하세요. 매핑한 본 사이의 보조 노드는 허용합니다 |
| 잘못된 가중치·합계·관절 인덱스 또는 스킨 접근자의 형식·바이트 정렬 | 미리보기를 차단합니다. 원본 도구에서 수정하며 자동 정규화·재작성하지 않습니다 |
| JOINTS/WEIGHTS 세트가 두 개 이상 | 모든 세트를 검사하지만 현재 뷰어가 네 영향값만 사용하므로 미리보기를 보류합니다 |
| 스킨 메시 월드 변환의 역행렬이 없음 | 바인드 검사는 통과할 수 있지만 현재 뷰어가 변환을 안전하게 역산하지 못하므로 미리보기를 보류합니다 |
| 행렬과 TRS 필드 동시 사용 또는 명시적 로컬 노드 행렬의 전단 | 차단하며 원본 도구에서 로컬 변환을 수정하세요 |
| 바인드·휴지 자세 검토 경고 | 원본 자세를 확인하세요. 관절 월드 행렬 × 역바인드가 서로 다른 것은 의도된 자세일 수 있습니다. 출력에는 명시적인 확인이 필요하며 원본 바인드를 보존합니다 |
| 버퍼·이미지의 외부 URI 또는 data URI | 차단하며 버퍼를 BIN에, 이미지를 버퍼 뷰에 내장하세요 |
| 압축·특수 재질을 포함한 모든 확장 | 차단하며 기본 glTF 버전을 준비하고 원본을 보관하세요 |
| 희소 접근자 또는 삼각형 이외 형상 | 차단하며 조밀한 속성과 삼각형으로 내보내세요 |
| 빈 접근자, 잘못된 POSITION·인덱스 형식 | 보고서와 함께 차단하며 비어 있지 않은 FLOAT VEC3 위치와 부호 없는 SCALAR 인덱스를 정규화 없이 출력하세요 |
| 잘린 파일, 잘못된 참조·순환·바이너리 범위 | 차단하며 원본 도구에서 복구·재출력하세요 |
| 빈 리소스·관계 배열 또는 잘못된 표면·morph 속성 | 출력을 차단합니다. 미사용 선택 배열을 생략하거나 원본 도구에서 형식·개수·정렬·유한값을 수정하세요 |
| 탄젠트만 있는 morph 타깃 | 출력을 차단합니다. 탄젠트 참조 제외로 타깃이 사라지지 않도록 POSITION 또는 NORMAL 변위 데이터를 준비하세요 |
| 입력 애니메이션·카메라 | 정적 미리보기이며 원본 데이터는 출력 GLB 컨테이너에 유지하지만 VRM 아바타 동작으로 사용하지 않습니다 |
| FBX, PMX/PMD, BLEND | 직접 읽지 않으며 적절한 기존 도구에서 GLB로 내보내세요 |

Blender 등에서 GLB를 준비할 때 축·크기·재질·내장 텍스처·본·가중치·애니메이션을 출력 후 확인하세요. 변환 중 기능이 손실될 수 있습니다. 형식별 애드온은 각자의 라이선스가 있으며 모델 권리도 그대로 적용됩니다. 원본을 보관하세요.

역바인드는 생략할 수 있으며 이때 단위 행렬을 사용합니다. 접근자는 스킨 관절 수 이상의 행렬을 포함할 수 있습니다. 비항등 변환과 바인드 형상 변환을 보존합니다. 수치 검사 통과가 제작자가 의도한 중립 자세나 자연스러운 변형을 증명하지는 않습니다. [검증 경계](../architecture.md#mapping-and-existing-skin-contracts)를 확인하세요.

WASM 초기화가 실패하면 `npm run build` 후 새로고침하세요. WebGL이 없으면 검사·보고서는 사용할 수 있으나 미리보기에는 WebGL이 필요합니다. 로더가 실패해도 검사 보고서는 남습니다. 실측한 최대 파일 크기·정점·텍스처·본 한도나 폭넓은 브라우저 지원을 약속하지 않으며 큰 파일은 메모리를 소진할 수 있습니다. [검증 기록](../validation.md)을 확인하세요.

## VRM 1.0 출력과 보고서 읽기

1. 기존 스킨이 있는 지원 GLB를 열고 모든 휴머노이드 매핑을 검토하며 매핑·바인드 오류를 해결합니다. 출력 가능 여부와 미리보기 가능 여부는 별도입니다. 뷰어의 제한만으로 원본 스킨을 무효화하지 않습니다.
2. 상단의 **Export**에서 **Avatar name**과 **Authors (one per line)**을 입력합니다. **Version**은 선택 항목입니다. 아바타 사용 대상, 상업적 사용, 저작자 표시, 수정, 폭력적 사용, 성적 사용, 정치·종교적 사용, 반사회·혐오 사용, 재배포의 모든 이용 조건을 선택합니다. 처음에는 선택값이 없으며 권리를 추정하거나 CC0를 부여하지 않습니다.
3. 권한이 있을 때만 **I can set these usage permissions**를 확인합니다. 출력에는 선택한 설정과 [VRM Public License 1.0](https://vrm.dev/licenses/1.0/)이 적용됩니다. 원본이 +Z 방향 T 자세의 휴머노이드이며 오른손 Y-up 좌표계와 미터 단위를 사용하는지 확인합니다. Rigloom은 이 자세·방향·단위 확인을 자동 검증하거나 원본에 다시 적용하지 않습니다. 바인드 자세 경고가 나오면 검토한 뒤 해당 확인란을 선택합니다.
4. **Export VRM 1.0**을 누릅니다. Worker 처리 중에는 설정·매핑 조작이 잠기며 **Cancel**로 출력도 취소합니다. 출력이 차단되면 진단을 표시하고 VRM 없이 **Save conversion report**로 보고서를 저장할 수 있습니다.
5. **VRM ready**가 표시되면 **Save VRM**과 **Save conversion report**를 모두 저장합니다. 다운로드 버튼은 Export 패널 위쪽에 나타납니다. **Conversion details**를 펼치면 처리 내역과 제한을 확인할 수 있습니다. 보고서에는 검사·변경·보존 데이터·제한과 원본·출력 SHA256 식별값이 들어 있습니다. 메타데이터나 매핑을 변경하면 준비된 다운로드를 무효화합니다. GLB를 교체하면 메타데이터와 확인란을 초기화하며 취소·교체된 작업이 이전 다운로드를 되살리지 않습니다.

출력은 원본의 이름만 바꾼 파일이 아니라 `VRMC_vrm`을 포함한 GLB입니다. 형상·스킨 가중치·역바인드·내장 이미지를 포함한 원본 BIN 바이트를 그대로 보존합니다. 원본 노드 인덱스·계층·변환·지원하는 PBR 재질·탄젠트 이외의 morph 데이터도 유지합니다. 메시·morph의 TANGENT 참조는 제외하고 보고하지만 해당 원본 BIN 데이터는 추적을 위해 남깁니다. 탄젠트만 있는 타깃은 몰래 삭제하지 않고 차단합니다.

애니메이션·카메라의 원본 데이터와 참조는 유지하지만 VRM 런타임에서 아바타 동작으로 사용하지 않습니다. PBR을 MToon으로 변환하지 않습니다. 표정·시선·1인칭 주석·스프링 본 물리·노드 제약을 생성하지 않습니다. VRM 저장과 수치 검사 통과가 자연스러운 변형, 제작자가 의도한 올바른 중립 자세, 모든 뷰어의 호환성을 인증하지는 않습니다. [검증 기록과 제한](../validation.md)을 확인하세요.

관절 드래그·가중치 생성·진단 동작·프로젝트 복원은 여전히 계획 단계입니다. 기존 선택적 손가락 본을 매핑해도 본을 생성하거나 형상에서 손가락을 분리하지 않습니다.

## 모델 권리와 로컬 처리

업로드 서비스는 설정하지 않았습니다. 런타임 리소스는 동일 출처이며 모델 URI 리소스는 로드 전에 차단합니다. 테스트는 합성 입력을 대상으로 하며 미래의 모든 배포를 보장하지 않습니다. 개발용 출력 테스트는 고정한 업스트림 스키마를 Git 제외 캐시에 내려받고 별도의 테스트 전용 VRM 로더를 사용하며 제품에서는 이 스키마를 가져오지 않습니다. 개인 모델은 저장소 대신 git 제외 경로 `.local/`에 둡니다. 다운로드·테스트 허용이 영상 사용·재배포 허용을 뜻하지 않습니다.

공개 릴리스·배포·배포물의 모델 편입은 해당 배치의 소유자 승인이 필요합니다. [한영 릴리스 정책](../release-policy.md)을 확인하세요.
