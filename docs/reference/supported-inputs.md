# 지원 입력과 제한

현재 검사기는 자체 포함 **glTF 2.0 GLB**의 일부 구조를 다룹니다. 제품이 목표로 하는 전체 리깅·VRM 변환 범위와는 다릅니다.

| 항목 | 현재 동작 |
|---|---|
| 장면 | 정확히 한 장면 필요. 여러 메시 허용. 캐릭터 수를 자동 판별하지 않음 |
| 바이너리 | JSON 청크와 선택적인 BIN 청크를 검사. 선언 길이·청크 정렬·버퍼 범위 확인 |
| 리소스 | 버퍼는 BIN, 이미지는 버퍼 뷰에 내장. 버퍼·이미지의 모든 URI는 `data:` 포함 차단 |
| 확장 | 선언되거나 사용된 모든 glTF 확장 차단. 압축·특수 재질 확장 포함 |
| 형상 | 삼각형 primitive와 조밀한 접근자만 허용. 희소 접근자 차단 |
| 위치 | 비어 있지 않은, 정규화하지 않은 `FLOAT VEC3` POSITION. 좌표는 유한수 |
| 인덱스 | 사용할 경우 정규화하지 않은 부호 없는 정수 `SCALAR`. 완전한 삼각형이며 위치 범위 안에 있어야 함 |
| 속성 | 접근자 오프셋·길이·stride와 primitive 내 정점 수 일치 확인 |
| 노드 | 참조와 계층 확인. 순환·다중 부모·부모가 있는 장면 루트 차단 |
| 재질 | 기본 glTF 재질을 뷰어로 전달. PBR을 MToon으로 바꾸지 않음 |
| 기존 스킨 | 개수와 노드 참조 목록화. 가중치·역바인드·휴머노이드 매핑 정확성은 미검증 |
| 스킨 없음 | 경고 후 표면 미리보기. 자동 리깅하지 않음 |
| 애니메이션 | 개수 확인만 수행. 정적 미리보기에서 재생하지 않음 |
| FBX·PMX/PMD·BLEND | 직접 가져오기 미지원 |

이미지 디코딩, 모든 행렬 저장 배치, 깊은 계층, 메모리 한계까지 검사기가 완전히 검증하지는 않습니다. 검사 통과 후에도 뷰어가 실패할 수 있습니다. 파일 크기·정점·텍스처·본의 실측 상한이나 폭넓은 브라우저 호환성은 아직 정하지 않았습니다.

현재 출력은 **검사 JSON**뿐입니다. 휴머노이드 매핑, 바인드·가중치 검증, 관절 편집, 스키닝, 진단 동작, 프로젝트 복원, VRM 1.0 출력은 제공하지 않습니다. 관련 제품 목표는 [요구사항](../../specs/product/requirements.md)에서 확인할 수 있습니다.

입력 준비와 오류 해결은 [검사 문제 해결](../how-to/troubleshoot-inspection.md)을 참고하세요. 원본 파일은 보관하고, 다른 도구를 통한 변환 결과의 축·크기·재질·텍스처·리그·애니메이션을 비교해야 합니다.
