# 사용자·기여자 문서 작성 규칙

루트 [AGENTS.md](../AGENTS.md)에 더해 이 디렉터리에서는 다음을 적용한다.

- 한국어 단일 문서로 관리한다. UI 식별자, 명령, 코드·진단 필드는 실제 표기를 유지한다.
- 튜토리얼은 따라 할 수 있는 한 가지 학습 경험, 작업 안내는 구체적인 목표 달성, 참조는 사실·형식, 설명은 개념·이유를 맡는다. 한 문서의 주된 목적을 유지하고 다른 목적은 링크한다.
- 현재 구현된 동작만 사용법으로 안내한다. 계획된 기능의 기준은 `specs/`, 작업 상태·커밋별 검증 증거는 `mydocs/` 또는 해당 이슈·PR에 둔다.
- 예제는 저장소의 생성 fixture를 사용한다. 외부 모델이나 비공개 파일을 추가하지 않는다.
- 디렉터리 README는 독자·목적과 문서 목록을 제공한다. 본문이나 상위 규칙을 반복하지 않는다. 내용 없는 미래 기능 문서는 만들지 않는다.
- 명령·진단 코드·지원 범위는 소스와 대조하고, 이동 시 링크를 갱신한다. 파일명·버튼·결과가 실제와 일치하는지 확인한다.
