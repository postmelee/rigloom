# 제품 요구사항

상태: 합의된 제품 범위. 아래 내용은 구현 완료를 뜻하지 않습니다. 현재 사용 가능한 기능은 [지원 범위](../../docs/reference/supported-inputs.md)에 따릅니다.

Rigloom의 목표는 브라우저에서 자체 포함 GLB를 받아 기존 리그를 검사하거나 휴머노이드 관절을 배치하고, 가중치를 보존·생성한 뒤 변형을 확인·수정하여 VRM 1.0, 편집 프로젝트, 변환 보고서를 내보내는 것입니다. Rust가 계산하고 WASM이 연결하며 Three.js가 표시합니다. [M2](roadmap.md)의 반자동 리깅이 핵심 경험이며 모든 모델의 완전 자동 리깅을 약속하지 않습니다.

## 입력과 원형 보존

- 한 캐릭터는 여러 메시일 수 있습니다. 몸·머리·눈·옷의 인스턴스와 관계를 검사하며, 기존 리그가 있거나 없는 T/A 포즈 휴머노이드를 대상으로 합니다.
- 유효한 가중치·계층·로컬/월드 변환·inverse bind·중립 표면과 특이한 비율을 보존합니다. 파일별 설정은 데이터이며 캐릭터 이름에 따른 코드 분기를 만들지 않습니다.
- 최초 입력 범위는 자체 포함 glTF 2.0 GLB, 삼각형, 일반 재질입니다. 리소스와 확장의 허용 정책을 명시하고, 미지원 구조는 코드·위치·설명·해결 방법으로 진단합니다. 데이터를 조용히 버리지 않습니다.
- FBX·PMX·PMD·BLEND 직접 입력은 초기 범위 밖입니다. 외부 도구로 준비하는 절차도 무손실 변환을 보장하지 않습니다.
- 제한값은 대표 파일의 크기·정점·텍스처·본 수, 브라우저·하드웨어, 시간·메모리 측정으로 결정합니다. drum-vrm의 제한을 그대로 사용하지 않습니다.

## 관절 배치와 스키닝

- 앞·위 방향, 바닥과 크기를 확인하고 골반·척추·머리·팔다리 관절을 드래그합니다. 앞/옆/자유 시점의 깊이 편집, 대칭 전환, X-ray 본, 모델 반투명, 선택 노드 정보, 필요 시 수치 입력, 실행 취소/재실행, 개별·전체 초기화를 지원합니다.
- 계층·좌우 오류를 감지합니다. 배치 모드와 동작 모드를 분리하고 관절 변경 시 종속 가중치·미리보기를 무효화합니다.
- 본 선분 거리, 표면 연결·거리 확산, 부피 기반 방식을 비교합니다. 최근접 본 배정만으로 품질을 승인하지 않으며 폐곡면 등 알고리즘의 전제조건을 확인합니다.
- 몸통/허벅지에 가까운 손, 겨드랑이·사타구니, 얇거나 열린 표면, 분리된 조각, 겹치는 옷, 단단한 장비, 작은 손발과 비대칭을 검사합니다. 형상을 몰래 삭제하여 보정하지 않습니다.
- 유한·비음수·정규화 가중치, 유효한 관절 인덱스, 가중치 없는 정점을 검사합니다. M3에서 영역 지정, 영향도 조절, 스무딩, 잠금, 색상 및 전후 비교를 제공하며 단일 본 강체 부착도 고려합니다.
- 손가락은 실제로 분리 변형할 수 있는 형상에서만 위치·길이·방향을 다룹니다. 주먹·장갑 표면을 자동으로 다섯 손가락으로 나누지 않습니다.

## 출력과 품질

- VRM 1.0을 실제로 직렬화하며 필수 휴머노이드 본의 유일성, 계층·참조, 좌표·단위 변환, bind·가중치, 텍스처·재질, 이름·저자·이용 조건, 확장·리소스를 검증합니다.
- PBR과 MToon을 구분하고 시각적 변경과 애니메이션 처리 결과를 보고합니다. 표정·시선·물리·특수 제약의 자동 생성은 후속 기능입니다.
- 권리를 모르면 CC0나 자유 이용을 기본값으로 가정하지 않습니다. 변환은 이용 권리를 부여하지 않습니다.
- 자체 생성한 어깨·팔꿈치·손목·무릎/스쿼트·발목 동작을 사용합니다. 주먹 동작은 적합한 손가락 리그에서만 실행합니다. 파일 유효성과 자연스러운 변형은 별도로 평가합니다.
- 네이티브 Rust, WASM, 브라우저 상호작용, 왕복 변환, 독립 로더/뷰어, 별도 합의된 로컬 drum-vrm 연동을 구분하여 검증합니다. 결정성과 중립 표면 보존이 수용 기준이며 스크린샷만으로 적합성을 입증하지 않습니다.

## 상호작용과 데이터

- 밝은/어두운 테마, 읽기 쉬운 글자, 일관된 SVG 아이콘, 넓은 뷰포트, 단계적 도구와 맥락별 설정, 취소, 해결 가능한 오류, 키보드 포커스·선택을 제공합니다.
- 모델 업로드 서비스는 기본 구성에 없습니다. 로컬 처리 주장은 실제 네트워크 요청으로 확인합니다. 단일 Worker가 단계와 리비전을 전달하며 오래된 결과는 새 작업을 덮어쓰지 않습니다. 공유 메모리·다중 스레드는 측정 근거가 있어야 도입합니다.
- 원본 식별자와 프로젝트 설정에 버전을 부여하고 보정 데이터를 보존하며 오래된 파생 계산을 무효화합니다. 모델 재배포는 기본 기능이 아닙니다.
