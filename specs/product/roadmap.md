# 제품 로드맵

마일스톤의 목표와 선행 관계를 정의합니다. 진행·승인 상태는 [GitHub 이슈](https://github.com/postmelee/rigloom/issues)와 해당 작업 기록을 확인합니다. 이 문서의 순서는 다음 구현을 승인하지 않습니다.

M1은 기존 리그 변환의 기반이며, M2가 요청된 반자동 리깅 MVP의 핵심 완료 기준입니다.

## 선행 관계

범위 및 초기 표준 조사 → 검사 → 의미 매핑과 bind·가중치 검증 → VRM 직렬화 → 독립 호환성 검증 → 관절 편집 및 프로젝트 저장 → 가중치 실험 → 동작 품질 개선 → 보정·손가락 → 호환성·성능 순서입니다.

#2의 알고리즘·라이선스 불확실성은 관련 구현을 채택하기 전에 해결해야 합니다. 검사 기능 완료로 연구 조건이 해결되지는 않습니다. 독립된 작업은 연구와 병행할 수 있지만 큰 순서 변경은 ADR 또는 이슈 근거를 남깁니다.

첫 구현 범위는 읽기 전용 GLB 검사, 단일 Worker, Three.js 정적 미리보기, JSON 검사 보고서입니다. 이후 엔진 경계는 안정적인 노드 인덱스·의미 관절·원본 리비전을 사용하며 Three.js 객체 이름에 의존하지 않습니다. 상세 경계는 [아키텍처](../architecture/overview.md)에 둡니다.
