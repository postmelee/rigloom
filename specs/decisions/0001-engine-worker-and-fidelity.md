# ADR 0001: 순수 Rust 검사와 단일 Worker

상태: 채택. 결정일: 2026-10-24.

## 결정

Rust가 모델 해석의 권위를 가집니다. `wasm-bindgen`은 버전이 있는 JSON 검사 결과를 노출합니다. `gltf 1.4.1`은 기본 기능을 끄고 `utils`·`names`만 사용하여 이미지·파일시스템을 암묵적으로 가져오지 않습니다. Three.js는 렌더링만 담당하며 로더가 무시할 수 있는 미지원 확장은 명시적인 JSON 정책 검사로 먼저 차단합니다.

하나의 module Worker를 사용하고 종료로 취소하며 단조 증가 리비전으로 오래된 결과를 거부합니다. 메인 스레드의 원본 읽기와 렌더러 파싱 비용은 별도 한계로 인정합니다. SharedArrayBuffer와 격리 헤더를 필수로 요구하지 않으며 실제 작업량 측정이 필요성을 보일 때 다시 검토합니다.

원본 바이트와 유효한 기존 리그를 보존합니다. Three.js 장면을 성급히 출력하거나 좌표를 굽지 않습니다. 향후 원본 모델·리그 편집·스킨 결과 경계는 bind/rest 일관성을 유지해야 합니다. sparse accessor, 모든 확장, URI 자원의 차단은 현재 구현 제한이며 glTF 또는 미래 Rigloom의 영구적 불가능을 뜻하지 않습니다.

## 결과

원본 중복 파싱과 WASM 복사에 메모리가 들지만 브라우저 객체 없이 경계를 검증할 수 있습니다. 브라우저와 네이티브 검사는 자체 생성한 같은 형상을 공유할 수 있습니다. 검사 완료가 휴머노이드 매핑·스킨 검증·VRM 출력을 완료하지는 않습니다.

[현재 아키텍처](../architecture/overview.md)에서 구현 경계를 확인합니다.
