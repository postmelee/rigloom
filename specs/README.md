| 선택의 이유와 결과          | [설계 결정](decisions/README.md)         |
| 릴리스·자산·의존성 원칙     | [정책](policies/README.md)               |

사용 방법은 [docs](../docs/README.md), 실제 이슈·PR 상태는 [GitHub](https://github.com/postmelee/rigloom/issues), 특정 작업의 계획·승인·실행 증거는 [mydocs](../mydocs/README.md)에 둡니다. 이 디렉터리에 세션 메모나 검사 횟수를 누적하지 않습니다.
