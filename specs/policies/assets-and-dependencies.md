# 자산과 의존성 정책

Rigloom 자체 소스의 이용 조건은 루트 [LICENSE](../../LICENSE)가 정합니다. 외부 코드·자료·자산에는 각자의 조건이 적용됩니다. 공개 시 고지는 [THIRD_PARTY_NOTICES](../../THIRD_PARTY_NOTICES.md)에서 관리합니다.

## 코드와 연구

- 새 의존성의 버전·커밋·라이선스를 고정합니다. 직접 의존성은 매니페스트, 해결된 전체 버전은 `Cargo.lock`과 `package-lock.json`에 보존합니다. 선택적 플랫폼 패키지도 잠금 파일에 포함합니다.
- 논문, 구현 코드, 데이터셋, 학습 가중치, 3D 모델·동작을 구분합니다. 저장소 라이선스 메타데이터만으로 모든 파일·모듈의 이용 권리를 단정하지 않습니다.
- GPL 등 호환성을 검토하지 않은 코드를 MIT 프로젝트에 복사하지 않습니다. C++ 구현 존재는 Rust/WASM 도입 가능성이나 수치 품질의 증거가 아닙니다.
- 후보 라이브러리의 출처·수치 성능·알고리즘 전제·모듈 및 solver 의존성의 조건을 확인한 뒤 채택합니다. 조사는 도입을 뜻하지 않습니다.

채택 의존성과 조사 근거는 [라이선스 대장](../../mydocs/tech/task_m0_2_licenses.md), [표준·알고리즘 조사](../../mydocs/tech/task_m0_2_standards-and-algorithms.md), 해결된 의존성 목록과 출처 스냅샷에서 추적합니다.

## 모델과 개인 자료

- 직접 생성한 fixture와 동작을 우선 사용합니다. 테스트 바이너리는 무시되는 `.local/` 또는 메모리에 두며 자동으로 공개 릴리스 자산에 넣지 않습니다.
- 개인 원본 모델, 대화 원문, 외부 다운로드, 인증 정보를 커밋하지 않습니다. `.local/`은 개인 보관·작업 자료입니다.
- 외부 자료는 출처·버전·해시와 함께 조사, 다운로드, 로컬 테스트, 공개 영상 사용, 재배포의 권한을 각각 기록합니다. 구매나 마켓 소개만으로 모든 권한을 가정하지 않습니다.
- 관심 있는 프랜차이즈 캐릭터는 승인된 자산이 아닙니다. 모델의 권리를 알 수 없으면 CC0나 자유 이용으로 채우지 않습니다.

릴리스 전 실제 포함 코드의 전체 라이선스 문구, 플랫폼 번들, 아이콘·폰트·모델 등의 목록을 점검하고 [배치 승인](release.md)을 받습니다.
