# 릴리스와 배포 정책

소유자의 명시적인 해당 배치 승인 전에 릴리스 태그 생성, GitHub Release 게시, Pages 등 모든 호스팅 배포, 공개 배포물에 모델 파일 편입을 실행하지 않습니다. 과거 다른 프로젝트의 승인, CI 통과, PR 병합, 마일스톤 완료는 릴리스 승인이 아닙니다.

## 승인에 필요한 결과물

승인 요청 전에 다음을 검토 가능한 상태로 준비합니다.

- 변경 요약과 정확히 검증한 커밋 SHA
- 실제 실행한 검사와 결과
- 알려진 제한과 배포 범위
- 실제 포함할 외부 코드·자산 및 이용 권리 목록

승인은 최종 릴리스 단계입니다. 릴리스 미승인이 이미 승인된 계획·조사·구현·검증·문서·PR 작업까지 막지는 않지만, 작업별 권한을 확대하지도 않습니다. 개별 구현과 병합은 해당 소유자 지시를 확인하며 자동 병합하지 않습니다.

## 상태와 기록

계획, 구현되었지만 미배포, 공개 배포를 구분합니다. localhost 개발 서버는 공개 배포가 아닙니다. 실제 배포했다면 해당 작업 보고 또는 승인된 릴리스 기록에 URL과 배포 SHA를 남깁니다. 배치별 승인·금지·검사 결과는 이 정책 본문에 누적하지 않고 해당 이슈·PR과 [작업 기록](../../mydocs/README.md)에 연결합니다.
